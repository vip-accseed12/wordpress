A responsive popup plugin that opens WPForms form ID 3989.

== Description ==
Use shortcode [dt_ss_popup] anywhere, including Elementor header and page templates via the Shortcode widget.

Default embedded form: [wpforms id="3989"]

Features:
- Button trigger with prefix classes: dt-ss-popup
- Click outside popup to close
- ESC key close support
- Mobile responsive modal layout

== Installation ==
1. Upload plugin folder to /wp-content/plugins/
2. Activate "My Popup"
3. Add shortcode [dt_ss_popup] to a post/page or Elementor Shortcode widget.
